Android 客户端是《酒馆德州》的独立 sideload 测试支线。本公开仓库只记录兼容性、
功能边界和产物校验信息，**不分发 APK，也不上传 Android/WSL 构建源码或构建环境**。

## v0.6.0 能力

- 完整保留飞行模式可玩的离线单机模式。
- 使用朋友局 JSON 协议 v2，连接 Windows 权威服务器；客户端不本地洗牌、发牌、
  判定行动或结算。
- 支持 2–9 个物理座位、创建者未入座、自由点击空位“＋”选座、取消准备后换座，
  以及至少两席有效且所有在座真人准备后未坐满开局。
- 房主可在指定空座添加服务器 AI，并选择动物身份、打法和买入；可对已有 AI 补码、
  换打法或移除。APK 不运行在线 Bot，也不为 AI 伪造连接身份。
- 支持服务器允许范围内的下注滑杆、个人视角牌桌、筹码飞行动画和权威结算顺序。
- 支持低于 100BB 的补码提示、目标栈补码、当前筹码大于 400BB 时非房主申请审批、
  真人与 AI 爆仓处置，以及房主暂停/恢复。
- 支持 WSS 粘贴、断线恢复凭据和 Android 前后台横屏恢复；APK 不内置固定公网地址。

v0.6.0 只连接协议 v2 服务。v0.5.x 及更早测试包属于历史兼容基线，不能用于当前
只接受 v2 的服务器。

## 人工验收口径

项目所有者已使用当前 Windows v2 权威服务器完成两台 Android 手机的人工可玩性
验收，确认两台手机可以进入同一朋友房并进行可玩对局。

这项结论是朋友局的可玩性验收，不等于完整设备认证，也不代表所有手机型号、
2/6/9 人布局、网络切换、锁屏恢复、所有补码/爆仓/AI/暂停边界都已逐项覆盖。
遇到新的设备、系统版本或网络环境，仍应重新执行针对性测试。

## 获取与安装安全

APK 仅由项目所有者私下提供。安装前应核对文件大小和上述完整 SHA-256；哈希不一致
时不要安装。

该 APK 是不可调试的内部 release 测试包，使用固定的内部测试证书以便覆盖旧测试版，
**不是 Google Play 生产签名，也不是应用商店正式发行版**。仅应从可信的项目所有者
处取得，并只用于朋友间测试。

朋友局 WSS 地址不包含在 APK 中。临时地址应通过私密渠道分享；一旦地址泄露，应
立即停止服务并重新启动，以取得新的地址。

## 仓库发布边界

本公开仓库可以包含 Windows 客户端、权威服务器、协议文档和脱敏使用说明，但不会
包含以下内容：

- APK、AAB 或商店发布包；
- Android/WSL 源码、Buildozer/p4a 工程、SDK/NDK、缓存、构建日志和内部报告；
- 签名私钥、恢复 token、真实 WSS 地址、Cloudflare 凭据或其他部署凭据；
- torch/rlcard、完整训练 checkpoint 或手机端训练环境。

服务器启动方法见 [朋友局服务器快速开始](FRIENDS_SERVER_QUICKSTART.md)。
